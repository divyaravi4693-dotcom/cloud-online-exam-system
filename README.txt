CLOUD-BASED ONLINE EXAMINATION AND RESULT MANAGEMENT SYSTEM
===========================================================

Project files
-------------
index.html  - Website layout and dashboard
style.css   - Styling and responsive design
script.js   - Exam questions, answer selection, scoring and result table

How to run in VS Code
---------------------
1. Extract the ZIP file.
2. Open the extracted cloud-online-exam-system folder in VS Code.
3. Open index.html.
4. Right-click the editor and choose "Open with Live Server".
   If Live Server is not installed, install the "Live Server" extension.
5. You can also double-click index.html to open it in a web browser.

Features
--------
- Student dashboard and exam summary cards
- Three sample practice exams
- Multiple-choice questions
- Previous/next question navigation
- Automatic local score calculation
- Answer review and recent results table
- Responsive desktop and mobile layout

Important note
--------------
This is a front-end demonstration project. Exam questions and results run in the browser only.
It does not yet include real cloud hosting, a database, student authentication, server-side
exam security, or persistent results. Those require a backend and cloud service integration.
